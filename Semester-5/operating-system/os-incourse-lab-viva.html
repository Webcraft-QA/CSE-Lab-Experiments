Read these corrections before memorising the notes
  • Most supplied scheduling programs assume all arrival times are zero. The general formulas are TAT=CT−AT, WT=TAT−BT and RT=first start−AT for the stated single-burst model.
  • Whole-block allocation and split-hole allocation give different answers. The C fit programs support both: default whole blocks, or --split.
  • Unused memory is not always external fragmentation. Explain whether it lies inside an allocation, in unallocated partitions, or in scattered holes.
  • The notebook's “deadlock prevention” safety calculation is Banker-style avoidance. Global resource ordering is an actual prevention technique.
  • Unsafe does not mean already deadlocked. Banker's safety test releases Allocation into Work, not Max.
  • Wait for empty/full outside the buffer mutex. Dining Philosophers must test and reserve resources atomically; deadlock freedom alone does not guarantee fairness.

01 / Operating-system foundations

001What is an operating system?Basic

System software that manages hardware resources and provides services and abstractions for programs, such as processes, virtual memory and files.

002What is the kernel?Basic

The privileged core of an operating system. It manages protected resources and mediates operations that ordinary applications cannot safely perform directly.

003What is a system call?Basic

A controlled interface through which a program requests an OS service, such as opening a file or creating a process. It normally involves a transition into kernel execution.

004What is multiprogramming?Basic

Keeping multiple jobs available so the CPU can run another when one waits, improving resource utilization. It does not require multiple CPUs.

005What is multitasking?Basic

Sharing execution among tasks, often through frequent scheduling and preemption, so several activities make progress over time.

006Distinguish an OS from a shell.Intermediate

The OS manages resources and protection. A shell is a user interface and command interpreter that requests OS services; it is not the entire operating system.

007What is the difference between user mode and kernel mode?Intermediate

User mode restricts privileged operations. Kernel mode permits protected hardware and memory-management actions. Hardware mechanisms enforce the boundary rather than relying only on application cooperation.

008What is an interrupt?Intermediate

An event that transfers control to a handler, often caused asynchronously by hardware. A timer interrupt can let the OS regain control and reconsider scheduling.

009What is a trap or synchronous exception?Intermediate

An event caused by the current instruction, such as a system-call instruction, divide error or page fault. Terminology varies by architecture, so distinguish the cause and handling behavior.

010What is a real-time system?Intermediate

A system whose correctness depends on meeting timing requirements as well as computing correct results. Hard and soft deadlines have different consequences when missed.

011What is the difference between concurrency and parallelism?Intermediate

Concurrency means tasks have overlapping lifetimes or progress. Parallelism means tasks execute simultaneously on separate processing resources. A single CPU can support concurrency by interleaving work.

012Why are the lab programs called simulations?Intermediate

They calculate outcomes from input arrays and policy rules. They do not replace the host OS scheduler, allocate physical partitions, or directly evict the host's memory pages.

013Does a system call always cause a process context switch?Expert

No. It changes privilege context, but the same process may continue executing and return. A process switch occurs only if scheduling selects a different execution context.

014Why should an OS separate mechanism from policy?Expert

Mechanism provides a capability, such as switching contexts; policy decides when and whom to switch. Separation allows policies to change without redesigning every low-level operation.

015Why cannot one scheduling algorithm be called universally best?Expert

Workloads and objectives differ: response time, throughput, deadlines, fairness and overhead may conflict. State the assumptions and metric before comparing algorithms.

02 / Processes, threads and states

016What is a process?Basic

An executing program with its execution state and resources, including an address space and OS-maintained information. A program file alone is not a running process.

017What is a thread?Basic

An execution stream within a process with its own registers and stack. Threads in a process normally share its address space and many resources.

018What is a PCB?Basic

A Process Control Block stores information needed to manage a process, such as saved execution state, scheduling information, identifiers and resource references.

019Name the common process states.Basic

New, ready, running, blocked or waiting, and terminated. More detailed OS models may include suspended states.

020What is the ready queue?Basic

The set or queue of processes eligible to execute but not currently running. A blocked process is waiting for an event and is not ready.

021What happens during a context switch?Intermediate

The OS saves the current task's execution state and restores another's. Scheduler work, address-space changes and cache effects can add cost beyond saving registers.

022What is the difference between ready and blocked?Intermediate

A ready process only needs CPU service. A blocked process needs an event, such as I/O completion, before it can execute usefully.

023Explain running-to-ready and running-to-blocked transitions.Intermediate

Preemption can move a running process to ready. Waiting for I/O or a synchronization condition moves it to blocked. The reason for leaving the CPU matters.

024What is a CPU burst?Intermediate

A period of computation between waits such as I/O. The scheduling exercises simplify each job to one known CPU burst unless explicitly stated otherwise.

025Distinguish CPU-bound and I/O-bound work.Intermediate

CPU-bound work spends much time computing; I/O-bound work frequently waits for devices. Real applications can move between these behaviors during execution.

026What does a dispatcher do?Intermediate

It gives control of the CPU to the selected task, including the necessary context and execution-mode changes. The scheduler chooses; the dispatcher implements the transfer.

027What resources do threads share and not share?Intermediate

Threads normally share code, heap and open resources within a process, but have separate stacks and register state. Shared memory creates synchronization requirements.

028Why does a ready queue not always mean a simple FIFO data structure?Expert

A policy may require priorities, multiple queues, trees or other ordering structures. The term describes eligible work, not a mandatory implementation.

029Can a blocked process become running immediately after I/O completion?Expert

Usually it becomes ready first, then runs when scheduled. It may quickly preempt another task under the chosen policy, but readiness and execution remain distinct states.

030Why can adding threads fail to improve speed?Expert

A workload may be serial, lock-bound, memory-bound or limited by available cores. Scheduling, synchronization and communication overhead can outweigh useful parallel work.

03 / Scheduling metrics and Gantt charts

031What is arrival time, AT?Basic

The time a process becomes available to the scheduler in the model. If all arrivals are assumed zero, explicitly say so before calculating results.

032What is burst time, BT?Basic

The CPU service required by a process in the simplified exercise. It does not include time spent waiting in the ready queue.

033What is completion time, CT?Basic

The clock time when the process finishes its final CPU service. For preemptive scheduling it is the end of the last execution slice.

034What is turnaround time?Basic

TAT = CT - AT. It measures elapsed time from arrival to completion, including waiting and all other modeled delays.

035What is response time?Basic

RT = first CPU start time - AT. It measures time until the first service, not time until the whole job finishes.

036How is waiting time calculated in these lab models?Intermediate

WT = TAT - BT, because the model has one CPU burst and no I/O blocking. With additional blocked time, subtract that too when measuring ready-queue waiting.

037Why is CT equal to TAT in many supplied programs?Intermediate

They assume AT=0 for every process. The equality is a consequence of that assumption, not the general definition of turnaround time.

038When are response time and waiting time equal?Intermediate

In a nonpreemptive single-burst model, a process waits once before starting, so RT=WT. With preemption it can wait again, making total WT larger.

039What is a Gantt chart?Intermediate

A timeline of which process uses the CPU over each interval. Include idle intervals and any context-switch cost if the question specifies them.

040How are average waiting and turnaround times found?Intermediate

Add the per-process values and divide by the number of processes. Convert to floating-point before division when a fractional result is possible.

041What are throughput and CPU utilization?Intermediate

Throughput is completed jobs per unit time. CPU utilization is the fraction of the stated observation interval spent busy; clarify whether overhead counts as useful work.

042How do you check a scheduling answer quickly?Intermediate

Ensure each process receives exactly its burst time, no process runs before arrival, intervals do not overlap on one CPU, and CT, TAT, WT and RT follow their definitions.

043What does a negative waiting time usually indicate?Expert

An invalid input or a calculation error, such as subtracting burst time from the wrong completion time or scheduling a job before arrival. It is not a legitimate result in these models.

044Why can the same workload produce different valid Gantt charts?Expert

Equal priorities or burst lengths need a tie rule, and simultaneous arrival/quantum events need an ordering rule. State the convention before comparing outputs.

045Does low average waiting time guarantee fairness?Expert

No. An average can hide a process waiting extremely long. Inspect worst-case waiting, starvation behavior and response time as well.

04 / Practical: FCFS scheduling

046What does FCFS stand for?Basic

First Come First Served. Processes are selected in arrival order; for equal arrivals the lab uses input order.

047Is the usual FCFS CPU policy preemptive?Basic

No. Once selected, a process retains the CPU until it completes its current CPU burst or blocks.

048What is the aim of the FCFS practical?Basic

Simulate execution order and calculate each process's waiting and turnaround times, then their averages.

049What is the initial waiting time with all arrivals zero?Basic

The first selected process has waiting time zero, assuming the CPU is initially available and there is no setup overhead.

050What is the zero-arrival FCFS recurrence?Basic

WT[0]=0 and WT[i]=WT[i-1]+BT[i-1]. Then TAT[i]=WT[i]+BT[i]. These recurrences require the stated ordering and arrival assumptions.

051Trace bursts 24,3,3 in input order.Intermediate

P1 runs 0-24, P2 24-27 and P3 27-30. Waiting times are 0,24,27; turnaround times are 24,27,30.

052What are the averages for that FCFS example?Intermediate

Average WT=(0+24+27)/3=17. Average TAT=(24+27+30)/3=27 time units.

053What is the convoy effect?Intermediate

Short or I/O-oriented tasks can queue behind a long CPU burst, delaying their progress and potentially reducing balanced use of CPU and devices.

054How should FCFS handle different arrival times?Intermediate

Order by arrival, breaking ties consistently. Start each job at max(previous completion, its arrival), then calculate CT and TAT from that actual start.

055Give an FCFS example with an idle gap.Intermediate

P1 has AT=2,BT=3 and P2 AT=10,BT=2. CPU is idle 0-2 and 5-10; execution is P1 2-5 and P2 10-12. Both waiting times are zero.

056Why preserve process identifiers?Intermediate

The output must report the correct result for each original process, especially after sorting. An array position is not necessarily the process identity.

057What is the time complexity of the supplied zero-arrival calculation?Intermediate

O(n) once the order is known. Sorting unsorted arrivals would add the complexity of the chosen sorting method.

058Can ordinary FCFS starve a job already in a finite queue?Expert

With finite service times and no earlier task that never yields or finishes, it eventually runs. It can still experience very long waiting.

059Why is changing only the burst list insufficient to support arrivals?Expert

The algorithm must consider eligibility and CPU idle time. Prefix sums alone incorrectly assume continuous availability of every process from time zero.

060Why does a successful run not prove the source array bounds are safe?Expert

A small sample may avoid the error. An array of length 20 has indices 0-19; using indices 1 through 20 writes past its end even if smaller examples work.

05 / Practical: SJF and supplemental SRTF

061What is SJF?Basic

Shortest Job First selects the ready process with the smallest next CPU burst. The core lab version is nonpreemptive.

062What is SRTF?Basic

Shortest Remaining Time First is a preemptive variant that selects the ready process with the least remaining CPU service.

063How is zero-arrival nonpreemptive SJF implemented simply?Basic

Sort processes by increasing burst time, use a clear tie rule, then accumulate execution time as in FCFS.

064What information does SJF need?Basic

The next CPU burst length or an estimate. The lab reads exact values, whereas a real scheduler generally lacks perfect future knowledge.

065What is SJF's main starvation concern?Basic

A long waiting job may repeatedly lose to arriving short jobs. Aging or another fairness mechanism can reduce this risk.

066Trace SJF for bursts 6,8,7,3.Intermediate

Order is P4,P1,P3,P2. Execution intervals are 0-3,3-9,9-16,16-24. Waiting in that order is 0,3,9,16.

067Find SJF averages for 6,8,7,3.Intermediate

Total WT=28, so average WT=7. Total TAT=3+9+16+24=52, so average TAT=13.

068Why is a global burst sort wrong when arrivals differ?Intermediate

A short process may not yet exist in the ready set. At each dispatch choose the shortest eligible job, or explicitly move time forward if no job is ready.

069When should SRTF preempt the current process?Intermediate

When an eligible process has a shorter remaining service than the current one, subject to the stated tie rule. Compare remaining time, not original burst time.

070What are the results for SRTF jobs (AT,BT)=(0,8),(1,4),(2,9),(3,5)?Intermediate

The schedule is P1 0-1, P2 1-5, P4 5-10, P1 10-17, P3 17-26. CT is 17,5,26,10 in original process order.

071Find waiting times for that SRTF example.Intermediate

TAT=17,4,24,7. Subtract BT=8,4,9,5 to get WT=9,0,15,2. Average WT=6.5 and average TAT=13.

072How should an SRTF simulator represent an idle CPU?Intermediate

Use an explicit 'no selected process' state and advance to the next arrival. Do not decrement a fake process's burst as a substitute for idle time.

073Under what assumptions does SJF minimize mean waiting time?Expert

For a fixed set of jobs ready together, known burst lengths and no preemption cost, shortest-first order minimizes total waiting. Do not generalize the simple proof to every online or constrained setting.

074What is wrong with using array element 9 as a 9999 sentinel in the older SRTF code?Expert

It overwrites a real tenth process, assumes real bursts stay below the sentinel and may decrement the sentinel during idle time. Explicit selection state avoids these errors.

075Can the original exchange-sort code reverse equal-burst processes?Expert

Yes. Even if it swaps only when one burst is greater, nonadjacent swaps can move equal keys past each other. A stable sort or explicit secondary key is needed for a guaranteed FCFS tie rule.

06 / Practical: Round Robin

076What is Round Robin?Basic

A preemptive policy that cycles through the ready queue, allowing each task at most a time quantum before requeueing it if unfinished.

077What is the time quantum?Basic

The maximum CPU service allowed in one turn before time-based preemption. It must be positive in this simulation.

078What does remaining burst time store?Basic

CPU service still required by the process. Keep the original burst separately for waiting-time calculations.

079When does a process leave the RR queue permanently?Basic

When its remaining burst reaches zero. A completed process must not receive another CPU slice.

080What happens when remaining burst is less than the quantum?Basic

Run only for the remaining service, finish the process and give the CPU to the next ready process without wasting the unused quantum.

081Trace bursts 24,3,3 with quantum 4.Intermediate

P1 runs 0-4, P2 4-7, P3 7-10, then P1 10-14,14-18,18-22,22-26,26-30. The final repeated P1 slices have no competing ready job.

082What are RR metrics for that example?Intermediate

CT=TAT=30,7,10. WT=6,4,7 and RT=0,4,7. Average WT=17/3=5.666667; average TAT=47/3=15.666667.

083What happens when the quantum is very large?Intermediate

With all processes initially ready and quantum at least every burst, RR behaves as FCFS in the initial queue order.

084What happens when the quantum is very small?Intermediate

Tasks get frequent service, but real context-switch overhead can become large. The classroom simulation usually ignores that cost.

085Why is a simple repeated array scan valid in the supplied RR example?Intermediate

All jobs arrive at zero and start in a fixed circular order. With later arrivals, a proper ready-queue insertion rule is required.

086Why is zero quantum dangerous?Intermediate

Remaining work never decreases, so the loop may never terminate. Reject zero or negative quantum before entering the simulation.

087When should CT be recorded in RR?Intermediate

At the instant a process's remaining burst becomes zero. Intermediate end-of-slice times are not its final completion time.

088Does q=1 make RR exactly SRTF?Expert

No. RR still rotates fairly through eligible jobs; SRTF repeatedly chooses the smallest remaining work. They can produce different orders even with unit-time simulation.

089What must be specified for an arrival exactly at a quantum boundary?Expert

Whether that arrival is enqueued before or after the just-preempted process. Either consistent convention may be used in an exercise, but results can differ.

090How do you estimate quantum overhead?Expert

If every full quantum q is followed by switch cost s, useful fraction is approximately q/(q+s) under those assumptions. Final slices, idle intervals and same-process continuation can change the actual result.

07 / Practical: Priority scheduling

091What is priority scheduling?Basic

Select the eligible process with the highest scheduling priority. The core supplied program is nonpreemptive and assumes all arrivals zero.

092Does a smaller numeric value always mean higher priority?Basic

No universal convention exists. The supplied program sorts ascending, so a smaller number means higher priority in this guide.

093Can priority scheduling be preemptive?Basic

Yes. A newly ready higher-priority process may preempt the current one in a preemptive variant. The nonpreemptive variant waits for the current burst to end.

094What is aging?Basic

Gradually improving a waiting process's priority so low-priority work is less likely to starve.

095What data must stay together when sorting?Basic

Process identity, burst time and priority, plus any other attributes. Sorting only priority values destroys the relationship between jobs and their properties.

096Trace the supplied pairs (BT,priority)=(10,3),(1,1),(2,4),(1,5),(5,2).Intermediate

Order is P2,P5,P1,P3,P4. Intervals are 0-1,1-6,6-16,16-18,18-19.

097What are the averages for that priority example?Intermediate

WT in execution order is 0,1,6,16,18, totaling 41: average 8.2. TAT is 1,6,16,18,19, totaling 60: average 12.

098How should equal priorities be handled?Intermediate

Apply an explicit secondary rule, commonly FCFS. The included stable insertion sort preserves input order for equal priorities when all arrivals are zero.

099Distinguish static and dynamic priority.Intermediate

Static priority stays fixed in the model. Dynamic priority changes with behavior or waiting, for example through aging or feedback scheduling.

100Why can a high-priority process wait?Intermediate

It may be blocked on I/O, waiting for a resource, or behind a currently running task in a nonpreemptive policy. High priority does not make an unavailable resource appear.

101What is priority inversion?Intermediate

A high-priority task waits for a resource held by a lower-priority task. Medium-priority work can further delay the holder and lengthen the high-priority task's wait.

102What is priority inheritance?Intermediate

Temporarily boosting a lock holder's effective priority to that of a higher-priority waiter, so it can finish the critical work and release the resource sooner.

103Is aging the same as priority inheritance?Expert

No. Aging addresses long waits and starvation; inheritance addresses resource-related priority inversion. They use different triggers and solve different problems.

104Why can priority scheduling hurt average waiting time?Expert

Priorities may favor long or important jobs over short ones. It optimizes priority policy rather than necessarily minimizing the mean waiting metric.

105Why is sorting all jobs once insufficient for preemptive priority with arrivals?Expert

Eligibility and priorities may change over time. The simulator must reconsider ready work at relevant events and save remaining service when preempting.

08 / Contiguous allocation and fragmentation

106What is contiguous memory allocation?Basic

Assigning a process one continuous address range in the modeled memory. The allocator must find a large enough contiguous region.

107What is a hole?Basic

A free contiguous region available for allocation. Multiple separated holes cannot automatically satisfy one larger contiguous request.

108What is internal fragmentation?Basic

Unused space inside an allocated unit, such as a partition larger than the process occupying it.

109What is external fragmentation?Basic

Free space split among separated regions so a contiguous request may fail even when total free memory is sufficient.

110What is compaction?Basic

Relocating allocated regions to combine scattered free space into larger regions. It requires relocation support and incurs data movement cost.

111Is all free memory external fragmentation?Intermediate

No. A remaining single free region is free capacity, not automatically evidence of fragmentation. Explain whether scattered holes prevent a request from fitting.

112Give an external-fragmentation example.Intermediate

Two separated holes of 100 and 200 units contain 300 free units, but a contiguous 250-unit request fits neither. Without moving allocations or changing the model, it cannot be placed.

113What is coalescing?Intermediate

Merging adjacent free regions when memory is released. It combines existing neighboring holes without relocating allocated processes.

114How does splitting a hole work?Intermediate

Allocate the requested amount from a suitable hole and retain its remainder as a smaller free region. The remainder can satisfy later requests if the model permits reuse.

115What happens in a whole-block allocation model?Intermediate

One process reserves an entire chosen block. A used flag prevents another allocation in that block, and leftover capacity inside it is internal waste.

116Why can two correct fit programs produce different answers?Intermediate

One may reserve whole blocks while another splits and reuses residual holes. Block ordering and tie rules can also differ; compare assumptions before blaming the algorithm.

117What does allocation failure imply?Intermediate

No currently eligible block or hole fits under the stated model. It does not necessarily imply every byte is occupied or that smaller later requests must also fail.

118Does best fit always eliminate fragmentation?Expert

No. It minimizes the immediate residual among eligible regions, but can leave tiny holes and may perform worse for future requests. Long-term behavior depends on the workload.

119Why is compaction different from paging?Expert

Compaction physically moves contiguous allocations to consolidate holes. Paging permits noncontiguous physical placement through address translation, avoiding the same contiguous-allocation requirement.

120Can an allocator report total free space and still fail a request?Expert

Yes. It must consider the size of the largest suitable contiguous region, alignment and policy restrictions, not just the sum of free bytes.

09 / Practical: First, best and worst fit

121What is first fit?Basic

Scan regions in the defined order and choose the first one large enough for the request.

122What is best fit?Basic

Choose the smallest eligible region large enough for the request, equivalently minimizing the nonnegative immediate leftover.

123What is worst fit?Basic

Choose the largest eligible region, aiming to leave a relatively large remainder rather than a tiny one.

124What does the used-block flag mean in the supplied code?Basic

It marks a block already reserved for a process. When that flag is used without splitting, the remaining capacity is not available for another process.

125What should represent 'not allocated'?Basic

An explicit invalid index such as -1, checked before indexing the block array. A valid block number must never double as a failure marker.

126How does first fit behave on blocks 100,500,200,300,600 and requests 212,417,112,426?Intermediate

In whole-block mode: P1->B2, P2->B5, P3->B3, P4 fails. In split-hole mode P3 reuses B2's remainder; P4 still fails.

127How does best fit behave on that example?Intermediate

Both modes allocate P1->B4, P2->B2, P3->B3 and P4->B5. Their leftover values match immediately, but only split mode keeps those remainders available.

128How does worst fit behave on that example?Intermediate

Whole-block mode: P1->B5, P2->B2, P3->B4, P4 fails. Split mode: P1->B5, P2->B2, P3 reuses B5, P4 fails.

129Why does first fit stop its scan early?Intermediate

Once the first suitable region is found, later regions cannot change the first-fit choice. Best and worst fit ordinarily need to examine all candidates in an unsorted list.

130What is the simple array implementation's complexity?Intermediate

Up to O(processes x blocks). First fit may stop early but still has that worst-case bound; more sophisticated indexing can change performance.

131Why is a fixed best-remainder sentinel such as 9999 unsafe?Intermediate

A valid region with leftover 9999 or more may never be selected. Use chosen=-1 and compare candidate sizes only after a candidate exists, or use a justified bound.

132What should happen after one request fails?Intermediate

Report that request as unallocated. Continue checking later requests if the task permits, because a smaller later request may fit. Do not silently suppress its result.

133Why is the supplied best-fit print loop problematic?Expert

It stops when parray[i]==0, so one failed allocation can hide later results. A per-process allocation status and a complete reporting loop avoid that omission.

134What does '--split' change in the included C programs?Expert

It subtracts a request from the chosen hole and allows its remainder to be reused. Without the option the program matches the whole-block flags model. Neither mode includes deallocation or coalescing.

135What must you say if the examiner's expected mapping differs from yours?Expert

State region order, whole-block versus split-hole behavior and tie rule. Then trace the first differing allocation; this usually identifies the model mismatch.

10 / Practical: MFT and MVT

136Expand MFT in this syllabus.Basic

Multiprogramming with a Fixed number of Tasks. The lab models fixed-size memory partitions, with at most one allocated process per partition.

137Expand MVT in this syllabus.Basic

Multiprogramming with a Variable number of Tasks. Partitions are sized dynamically to process requests; the supplied program simplifies this to subtraction from remaining memory.

138What fragmentation is associated with fixed partitions?Basic

Internal fragmentation when a process occupies less than its reserved partition. There can also be an unused tail if total memory is not a multiple of partition size.

139What fragmentation is associated with variable contiguous partitions?Basic

External fragmentation can arise as allocations are freed and holes form. A simple no-freeing subtraction program does not simulate those scattered holes.

140How many equal fixed partitions fit?Basic

floor(total memory / partition size). The unpartitioned tail is total memory modulo partition size.

141Solve MFT for total 1000 and partition size 300.Intermediate

There are three complete partitions and a 100-unit tail. The tail is reported separately from unused space inside allocated partitions.

142Allocate requests 275,400,290,293,100 in that MFT example.Intermediate

P1, P3 and P4 occupy the three partitions. P2 is too large; P5 has no partition left. Internal waste is 25+10+7=42.

143Is an unused whole partition internal fragmentation?Intermediate

Not of an allocated process. It is unallocated capacity. Distinguish unused partitions, unpartitioned tail and internal waste in occupied partitions.

144Trace MVT pool 1000 with requests 400,275,550.Intermediate

Allocate 400, leaving 600; allocate 275, leaving 325; reject 550. Total allocated is 675 and free remaining is 325.

145Why is 'memory is full' imprecise for the failed 550-unit request?Intermediate

There are still 325 free units. The request is too large for the remaining capacity, but a smaller request could fit.

146How does the included MVT program differ from the supplied loop?Intermediate

It takes a bounded number of requests and continues after a failure. It calls remaining capacity 'free memory' rather than automatically labelling it external fragmentation.

147What additional structures are needed for realistic MVT?Intermediate

Track allocated regions and a free-hole list with addresses and sizes; implement release, adjacency checks, coalescing and placement policy. A single remaining-memory integer is insufficient.

148Can compaction solve a request larger than total free memory?Expert

No. It can combine scattered free regions but cannot create additional capacity. A request exceeding total available space still cannot fit.

149Why can MFT reject a job when plenty of total memory is unused?Expert

A process cannot span partitions in this model. If its request exceeds the largest permitted partition, summing several unused partitions does not help.

150Does MVT mean there is no internal waste in real systems?Expert

The ideal lab model assigns exactly the requested amount. Real allocators can introduce alignment, metadata and rounding overhead, so the statement requires that idealization.

11 / Paging and page faults

151What is a page?Basic

A fixed-size unit of a virtual address space. Paging maps virtual pages onto physical memory frames.

152What is a frame?Basic

A physical-memory unit with the same size as a page in the simple paging model. Any compatible free frame can hold a page.

153What is a page table?Basic

A structure mapping virtual page numbers to physical frame information and attributes such as validity and protection.

154What is a page fault?Basic

An exception caused when a memory reference requires page-related handling, commonly because a valid virtual page is not resident. Invalid or prohibited accesses require different handling from demand loading.

155What is a page hit in the replacement exercise?Basic

The referenced page is already in the simulated frame set, so no page load or replacement is needed for that reference.

156What is a reference string?Intermediate

The ordered sequence of virtual page identifiers accessed by a process or workload. The replacement simulation processes it from left to right.

157Does filling an empty frame count as a fault?Intermediate

Yes. The referenced page was absent. Replacement is unnecessary, but the miss is still counted in the lab fault total.

158When is replacement required?Intermediate

When a needed page is absent and no eligible free frame remains. Choose a victim using the policy, preserving dirty data as necessary in a real system.

159What is a dirty page?Intermediate

A page modified since its backing copy was last synchronized. Evicting it may require a write-back; a clean page may be discardable without that write.

160What is the page-fault ratio?Intermediate

Number of faults divided by number of references. Hit ratio is hits divided by references, and their sum is one in this simplified two-outcome model.

161Why initialize frame entries?Intermediate

The simulator must distinguish empty slots from resident pages. An uninitialized array can falsely report hits or choose invalid victims.

162Why is page number zero valid here?Intermediate

Page IDs are nonnegative and zero is a legitimate identifier. The included programs use -1 only internally for an empty frame and print '-' for that state.

163Is a page fault always a disk operation?Expert

No. It may be resolved by zero-fill, a page already cached in memory, copy-on-write or another in-memory action. Some faults do require storage I/O.

164Does paging eliminate every kind of fragmentation?Expert

It avoids the need for a process's physical allocation to be contiguous, but can waste space within its final page and adds page-table overhead.

165Why can minimizing faults alone be insufficient for performance?Expert

Victim write-back cost, access latency, CPU overhead, prefetching and interference also matter. The lab compares fault counts under equal simplified costs.

12 / Practical: FIFO page replacement

166What does FIFO replace?Basic

The page that has been resident longest since its most recent loading, regardless of how recently it was accessed.

167What data structure naturally represents FIFO?Basic

A queue of resident pages. A fixed frame array with a circular replacement pointer is a simple equivalent implementation.

168Does a hit move the FIFO pointer?Basic

No. A hit does not reload the page or change its insertion age in ordinary FIFO.

169How does a circular replacement pointer advance?Basic

next=(next+1)%frame_count after inserting on a fault. Frame count must be positive to avoid invalid modulo operation.

170What is Belady's anomaly?Basic

For some reference strings, increasing frame count makes FIFO incur more page faults instead of fewer.

171Trace 1,2,1,3 with two initially empty frames.Intermediate

1 faults, 2 faults, 1 hits, then 3 replaces 1 because it was loaded first. Total faults are three; the hit on 1 does not make it newer in FIFO.

172What is FIFO's result for the standard 20-reference lab string with three frames?Intermediate

For 7,0,1,2,0,3,0,4,2,3,0,3,2,1,2,0,1,7,0,1, FIFO has 15 faults and 5 hits.

173What are FIFO faults for only the first ten references of that string?Intermediate

Nine faults. The fifth reference, page 0, is the only hit among those first ten references under three-frame FIFO.

174Give the standard anomaly example.Intermediate

For 1,2,3,4,1,2,5,1,2,3,4,5, FIFO produces 9 faults with three frames and 10 faults with four frames, starting empty.

175What changes on a fault when frames are not yet full?Intermediate

The next empty frame is filled and the insertion order advances. Do not count a fictitious evicted page while filling initial free space.

176Why print frame contents on hits as well?Intermediate

It makes the trace auditable and shows that state did not change. The supplied FIFO program prints blank frame rows on hits, which can confuse manual checking.

177What is the simple FIFO simulator complexity?Intermediate

O(reference_count x frame_count), because each reference searches all frames for a hit. Pointer replacement itself is O(1).

178Why does a hit not protect a frequently used page in FIFO?Expert

FIFO records loading age rather than access recency or frequency. A heavily used old page can still be next for eviction.

179Does every increase in FIFO frames cause the anomaly?Expert

No. It is possible for particular strings and frame counts, not an inevitable result. Trace the same reference sequence under both capacities.

180Why can a wrong pointer update still pass a simple test?Expert

A sequence with no repeated references gives no hit case to expose the bug. Include a hit immediately before a later miss when testing FIFO behavior.

13 / Practical: LRU page replacement

181What does LRU stand for?Basic

Least Recently Used. It evicts the resident page whose latest access is furthest in the past.

182What information does timestamp-based LRU keep?Basic

The most recent reference index or access time for each resident page. Smaller timestamps represent older last use.

183Must LRU update a timestamp on a hit?Basic

Yes. A hit is a new access and changes recency, even though the page does not move to a different frame.

184What happens on a miss with an empty frame?Basic

Fill an empty frame and record the current access time. Victim selection among resident pages is unnecessary until frames are full.

185How does LRU differ from FIFO?Basic

FIFO uses time of loading; LRU uses time of most recent access. Hits affect LRU's recency but not FIFO's insertion order.

186Trace 1,2,1,3 with two frames under LRU.Intermediate

Load 1, load 2, hit 1, then replace 2 with 3 because 2 is least recently used. Three faults occur, but the victim differs from FIFO.

187What is LRU's result for the standard 20-reference string and three frames?Intermediate

It produces 12 faults and 8 hits. Recompute timestamps on every reference to reproduce that result.

188How can a stack represent exact LRU?Intermediate

Keep pages ordered by recency and move the referenced page to the most-recent position. Evict the least-recent resident page when required.

189What is locality of reference?Intermediate

Programs often reuse recently accessed data and nearby addresses. Temporal locality helps explain why recency-based policies can perform well.

190What is the simple timestamp LRU complexity?Intermediate

O(R x F) for R references and F frames: search for a hit and, on a full miss, scan for the oldest timestamp.

191How does LRU break a timestamp tie?Intermediate

The classroom implementation uses the first frame encountered. With unique reference indices, distinct occupied pages normally have distinct latest-access times.

192What bug makes LRU behave closer to FIFO?Intermediate

Updating the age only when a page is loaded. Correct LRU updates latest use on every hit as well as on insertion.

193Why does LRU avoid Belady's anomaly?Expert

Under the standard model it has the stack property: the resident set for k frames is contained in that for k+1 frames. More frames therefore cannot increase misses for the same reference sequence.

194Why is exact LRU expensive in a real OS?Expert

Every memory access would need to maintain exact ordering or time information. Hardware support and software overhead motivate approximations such as Clock.

195Is LRU always as good as Optimal?Expert

No. LRU infers future usefulness from past activity; Optimal uses the actual future sequence. A pattern that defeats recency can give LRU more faults.

14 / Practical: Optimal replacement

196What does Optimal replace?Basic

The resident page whose next use lies furthest in the future, or one that will never be used again.

197Why is it called Optimal?Basic

For a known fixed reference sequence and frame count in the standard model, it minimizes the number of page faults.

198Why is it not directly implementable online?Basic

A real OS generally does not know the exact future reference string. The lab can look ahead because the whole sequence is provided as input.

199What is its practical role?Basic

A benchmark for comparing feasible policies and a useful way to understand the best achievable fault count under the model.

200What if a page is never referenced again?Basic

It is an ideal victim. If several pages are never reused, any one of them may be selected without increasing the optimal fault total.

201What is Optimal's result for the standard 20-reference string and three frames?Intermediate

Nine faults and eleven hits. Victim frame layouts can differ when there are ties, while the minimum fault count remains the same.

202How is the next-use index found?Intermediate

For each resident page, scan forward from the next reference until it appears. Use an explicit beyond-end value when it never appears again.

203Should Optimal replace a page on a hit?Intermediate

No. The requested page is already resident. Lookahead victim selection is needed only on a miss with no free frame.

204How are empty frames handled?Intermediate

Fill an empty frame before evicting any resident page. A faulty implementation that evicts too early can waste available capacity.

205For frames [1,2,3] and future references 2,1,4,3, which victim is best now?Intermediate

Page 3 is used latest among those residents. If a new page must be inserted before that future sequence, replace 3.

206Why must next-use information be reset for each replacement?Intermediate

The remaining future sequence changes at every step. Stale positions can choose a page based on a future access that has already occurred.

207What is the naive lookahead simulator complexity?Intermediate

Up to O(R squared x F), because each full miss may scan much of the remaining reference string for each frame. More advanced preprocessing can improve this.

208Can Optimal have more faults than FIFO on the same fixed model and input?Expert

No. If a reported Optimal count is higher, check the implementation, initial contents, frame count or reference string; the comparisons may not match.

209Does a different tie victim prove one Optimal trace is wrong?Expert

No. If multiple resident pages have no future use, several frame states can be equally optimal. Compare declared tie rules and final fault counts.

210Is least frequently used the same as Optimal?Expert

No. Frequency counts past accesses, while Optimal considers next future use. A historically frequent page might never be needed again.

15 / Deadlock fundamentals

211What is deadlock?Basic

A set of processes cannot proceed because each waits for an event or resource release that another process in the set must cause.

212Name the four Coffman conditions.Basic

Mutual exclusion, hold and wait, no preemption of the relevant resources, and circular wait. All are necessary for the classic resource deadlock situation.

213What is hold and wait?Basic

A process holds one or more resources while waiting to acquire additional resources.

214What does no preemption mean in deadlock theory?Basic

A resource cannot be forcibly taken away safely; it must be released by its holder. This is different from preempting CPU execution.

215What is circular wait?Basic

A cycle of processes each waiting for a resource held by the next process in the cycle.

216Distinguish deadlock and starvation.Intermediate

In deadlock, involved processes mutually block progress. In starvation, a process is indefinitely denied service while other work can continue.

217What is deadlock prevention?Intermediate

Designing rules that break at least one necessary condition, such as imposing a global resource acquisition order to prevent circular wait.

218What is deadlock avoidance?Intermediate

Examining prospective allocations and allowing only those that retain a safe state under declared future claims. Banker's algorithm is the main lab example.

219What is deadlock detection?Intermediate

Allowing allocations without guaranteeing safety, then checking whether a deadlock has occurred and taking recovery action.

220What is a safe state?Intermediate

A state with at least one ordering in which every process can obtain its remaining declared resources and finish, with completed processes releasing their holdings.

221Is every unsafe state already deadlocked?Intermediate

No. Unsafe means the model cannot guarantee completion for all possible requests up to the declared maxima. Actual requests may still permit progress.

222Does a cycle in a resource-allocation graph always prove deadlock?Intermediate

With one instance of each resource type, a cycle is sufficient. With multiple instances, a cycle alone is not generally sufficient.

223How does lock ordering prevent circular wait?Expert

Require every thread to acquire locks in the same global order. A cycle would require contradictory increasing order, so the circular-wait condition cannot form under compliant use.

224What are costs of deadlock recovery?Expert

Terminating tasks or preempting resources can lose work, corrupt partially updated state or require rollback. Recovery must respect resource semantics.

225Is an OS's ability to preempt a CPU enough to prevent all deadlocks?Expert

No. A preempted process can still hold locks or other resources. CPU scheduling does not automatically release resources safely.

16 / Practical: Banker's algorithm

226What does Available contain?Basic

Currently unallocated instances of each resource type. It is a vector, not the total inventory including resources already held.

227What do Max and Allocation contain?Basic

Max is each process's declared maximum claim per resource type; Allocation is what it currently holds. Both are process-by-resource matrices.

228How is Need calculated?Basic

Need[i][j] = Max[i][j] - Allocation[i][j]. A negative result means the supplied state violates the declared maximum and should be rejected.

229What is a safe sequence?Basic

An ordering of processes that can all hypothetically finish using currently free resources plus holdings released by earlier finishes.

230What is Work initialized to?Basic

A copy of Available. Finish flags are initially false. The safety test changes Work without pretending the real processes actually executed.

231When can a process be chosen in the safety test?Intermediate

When it is unfinished and Need[i][j] <= Work[j] for every resource type j. A scalar sum comparison is insufficient.

232What is added to Work when a process hypothetically finishes?Intermediate

Its current Allocation, not its Max. The additional Need would be borrowed and returned within the hypothetical execution, leaving a net gain equal to Allocation.

233When is the state declared unsafe?Intermediate

When unfinished processes remain and a full scan finds none whose Need fits Work. No complete safe sequence was found under the model.

234What are the first checks for a request?Intermediate

Require nonnegative Request, Request <= Need for the requester, and Request <= Available, component by component. Exceeding Need is invalid; unavailable resources require waiting.

235How is a tentative request applied?Intermediate

Available decreases by Request; the requester's Allocation increases by it; Need decreases correspondingly. Run the safety test on that tentative state.

236What happens if the tentative state is unsafe?Intermediate

Do not grant the request. Restore the original state and make the requester wait, rather than committing an allocation that removes the safety guarantee.

237Is the safe sequence unique?Intermediate

Usually not. Several processes may be eligible at a step. The included code scans increasing process IDs, so its returned sequence is deterministic for the given input.

238Why is Need <= Work a componentwise test?Expert

Resource types are not interchangeable. Free printers cannot satisfy a request for memory simply because total instance counts happen to match.

239What assumptions limit Banker's practical use?Expert

Processes must state credible maximum claims, the inventory model must be known, and completion must release resources. Dynamic behavior and checking cost can make these assumptions inconvenient.

240Does printing a safe sequence implement the full request algorithm?Expert

No. That only demonstrates the safety check. A complete request demonstration also validates a request, tries it, reruns safety, and grants or rolls back the change.

17 / Producer-consumer and synchronization

241What is a race condition?Basic

Correctness depends on the timing or ordering of concurrent accesses to shared state without sufficient synchronization.

242What is a critical section?Basic

Code that accesses shared state requiring controlled concurrent access. The buffer, indices and counters in this practical are protected by a mutex.

243What is the bounded producer-consumer problem?Basic

Producers insert items into a finite buffer and consumers remove them. Synchronization must prevent overflow, underflow and conflicting buffer updates.

244What is a semaphore?Basic

A synchronization object manipulated by atomic wait and signal operations. Counting semaphores can track available buffer slots and available items.

245What is a mutex?Basic

A lock that provides exclusive ownership of a critical section. It protects the shared buffer while a producer or consumer updates it.

246What are the initial synchronization values for capacity five?Intermediate

empty=5, full=0 and the mutex is initially unlocked. A textbook semaphore used as the mutex would start at 1.

247Explain the producer's operation order.Intermediate

Create an item; wait(empty); lock the mutex; insert at in; advance in modulo capacity; unlock the mutex; signal(full). Never insert before reserving an empty slot.

248Explain the consumer's operation order.Intermediate

wait(full); lock the mutex; remove at out; advance out modulo capacity; unlock the mutex; signal(empty); use the item. Never remove before reserving an available item.

249Why wait for empty or full before acquiring the mutex?Intermediate

Waiting while holding the buffer mutex can prevent the other side from changing the condition being awaited, causing deadlock.

250Why use modulo arithmetic for in and out?Intermediate

(index+1)%capacity wraps the index to zero at the end, making a circular buffer. Separate counts or semaphores distinguish full from empty when in equals out.

251Why is x++ not automatically thread-safe?Intermediate

It involves a read-modify-write operation that can lose an update if performed concurrently without synchronization. A mutex or an appropriate atomic operation is needed.

252What termination rule is used in the corrected example?Intermediate

Five producers each insert five unique items and five consumers each remove five items. All 25 items must be consumed exactly once, and main joins all threads before destroying synchronization objects.

253Is empty+full always exactly the buffer capacity during execution?Expert

Not necessarily at every instant: a thread can reserve a semaphore unit before publishing the corresponding update to the other semaphore. At quiescent boundaries with no reserved operations the total equals capacity.

254Why can mismatched producer and consumer totals hang this finite example?Expert

Extra consumers can wait forever for nonexistent items, or excess production can leave producers blocked on a full buffer. General designs use a coordinated shutdown protocol or termination markers.

255Does a successful test prove every possible concurrent execution correct?Expert

No. Repeated runs exercise only some interleavings. Reason about invariants, operation ordering and synchronization as well as checking observed totals and item uniqueness.

18 / Virtual-memory and address-translation follow-ups

256What is virtual memory?Basic

An abstraction that gives processes address spaces translated and protected by the OS and hardware, allowing physical placement to differ from virtual layout.

257What is a virtual address?Basic

An address generated in a process's virtual address space. Translation determines the physical location or raises an exception.

258What is a TLB?Basic

A Translation Lookaside Buffer caches address translations and related permissions, reducing repeated page-table lookup cost.

259What is demand paging?Basic

Bringing a page into memory when it is needed rather than loading every page in advance.

260What is thrashing?Basic

Excessive paging caused when active workloads lack enough resident memory for useful locality, leaving little time for productive execution.

261Split an address into page number and offset.Intermediate

For page size P, page number=floor(address/P) and offset=address mod P. With a power-of-two page size, low address bits form the offset.

262Translate virtual address 2500 with 1024-byte pages if page 2 maps to frame 7.Intermediate

Page number=2 and offset=452. Physical address=7 x 1024 + 452 = 7620.

263What is the difference between a TLB miss and a page fault?Intermediate

A TLB miss means the translation is not cached. The page may still be resident and translated by a page-table walk; absence from physical memory is a different condition.

264What is temporal locality versus spatial locality?Intermediate

Temporal locality is reuse of recently accessed items. Spatial locality is access to nearby addresses. Different optimizations exploit each pattern.

265What is a working set?Intermediate

The pages used over a recent execution interval. Keeping active working sets resident helps reduce excessive faults.

266Distinguish local and global replacement.Intermediate

Local replacement chooses among a process's allocated frames. Global replacement can choose frames across processes, allowing one workload to affect another's residency.

267What is copy-on-write?Intermediate

Processes initially share read-only physical copies; when one writes, the system creates a private copy as needed. This avoids unnecessary eager copying.

268Can increasing multiprogramming worsen throughput?Expert

Yes. If active working sets exceed memory, increased paging and contention can outweigh the benefit of more runnable work and lead to thrashing.

269Why can larger pages have mixed effects?Expert

They reduce the number of page-table entries and can improve translation coverage, but may increase internal waste and transfer unnecessary data. Workload locality matters.

270What is the cost of a page table for a 32-bit byte address space with 4 KiB pages and 4-byte entries?Expert

There are 2^20 virtual pages, so a flat page table has 2^20 x 4 bytes = 4 MiB, before extra metadata. Multi-level designs can avoid allocating unused portions.

19 / Dining Philosophers

271What does Dining Philosophers demonstrate?Basic

Several concurrent participants need pairs of shared resources. It illustrates mutual exclusion, deadlock and starvation in resource allocation.

272Why are five forks shared by five philosophers?Basic

Each fork lies between two neighbors, and each philosopher needs both adjacent forks to eat. Resources can conflict even though participants have separate execution streams.

273What states are used in the supplied approach?Basic

THINKING, HUNGRY and EATING. HUNGRY records a request; EATING records that both neighboring resources have been reserved.

274Can neighboring philosophers eat simultaneously?Basic

No, because they share a fork. Nonadjacent philosophers can eat simultaneously when their other neighbors do not conflict.

275What does the global mutex protect?Basic

Shared state checks and state changes, including deciding whether a hungry philosopher may enter EATING. It is not intended to remain locked throughout eating.

276Why can picking up the left fork first cause deadlock?Intermediate

If everyone holds one fork while waiting for the next, a circular wait forms. Merely swapping names left and right for everyone does not solve the problem.

277Explain the test(i) operation.Intermediate

While holding the mutex, check that i is HUNGRY and neither neighbor is EATING. If so, change i to EATING and signal its private semaphore.

278Explain take_forks in the state-based algorithm.Intermediate

Lock the mutex, set HUNGRY, call test(i), unlock the mutex, then wait on i's private semaphore. Waiting outside the mutex allows neighbors to finish and grant permission.

279Explain put_forks in the state-based algorithm.Intermediate

Lock the mutex, set the current state to THINKING, test the left and right neighbors, then unlock. The release can make an adjacent hungry philosopher eligible.

280Why initialize every private semaphore to zero?Intermediate

A philosopher must obtain permission before eating. test(i) posts exactly when it reserves the forks for that philosopher.

281Is a signal lost if it occurs before sem_wait?Intermediate

No. The semaphore retains a count that the later wait can consume. This differs from incorrectly using an unprotected transient flag.

282How many philosophers can eat at once with five arranged in a ring?Intermediate

At most two, because no two adjacent philosophers may eat. The example may show less concurrency depending on thread scheduling and how short the simulated work is.

283Is the state-based solution guaranteed starvation-free?Expert

No fairness queue or bounded-wait rule is implemented. It prevents adjacent eating and avoids the circular hold-one-fork deadlock, but indefinite overtaking is possible in an ongoing workload without stronger fairness assumptions.

284Give two alternative deadlock-prevention designs.Expert

Acquire forks by a global numeric order, removing circular wait; or admit at most four of five philosophers to the fork-acquisition phase. Each needs correct release and separate consideration of fairness.

285Why avoid sleep while holding the global mutex?Expert

It needlessly prevents other philosophers from checking or releasing their states. Sleeping is not synchronization; any simulated eating delay belongs outside the short state-management critical section.

20 / C code, debugging and practical defense

286Why is stdio.h included?Basic

It declares standard input/output functions such as printf and scanf so the compiler can check their use correctly.

287Why does scanf usually need & for an integer variable?Basic

It must receive the address where the converted value is stored. Passing the integer's current value instead is a type and memory-access error.

288What are valid indices of int a[20]?Basic

0 through 19. Index 20 is out of bounds. One-based display labels do not require one-based array storage.

289What does break do versus continue?Basic

break exits the nearest loop or switch; continue skips the remainder of the current loop iteration and proceeds to the loop's next iteration step.

290Why initialize accumulators and flags?Basic

Automatic local variables otherwise contain indeterminate values. Averages, allocation checks and completion tests can fail unpredictably if they start from garbage state.

291Why preserve original burst time in a preemptive program?Intermediate

Remaining time is reduced during simulation, but WT=TAT-BT needs the original CPU service. Overwriting the only copy makes the final metrics wrong.

292Why validate process count and frame count?Intermediate

Prevent array overruns, division by zero, modulo by zero and meaningless empty simulations. The allowed count must match the actual declared capacity and indexing convention.

293Why check input conversion?Intermediate

Invalid text or missing data can leave values unchanged or uninitialized. The included programs parse bounded integer tokens and reject malformed or out-of-range input.

294What is the issue with sum/n when both are integers?Intermediate

Integer division discards the fractional part before assignment to a floating variable. Use a floating accumulator or convert an operand before dividing.

295Why avoid conio.h, clrscr and getch in portable C?Intermediate

They are not part of standard C and may be unavailable in the exam compiler. Standard input/output is enough for these algorithms.

296What is the difference between compile-time and logical errors?Intermediate

Compile-time errors prevent a valid build, while logical errors can produce wrong results in a program that compiles. Compiler warnings and known-answer tests address different problems.

297What should you explain when defending the program?Intermediate

State input meaning, assumptions, main arrays, selection rule, update rule, stopping condition, output calculation and one edge case. Connect each important loop to the algorithm.

298Why is static zero initialization not a complete allocation-failure solution?Expert

A zero index can still refer to a valid element or mask a missing result. Use explicit success/failure state and avoid indexing until a candidate was actually selected.

299What tests are stronger than repeating the sample input?Expert

Include ties, repeated hits, exact fits, failed requests followed by smaller ones, idle CPU gaps, invalid counts and unsafe Banker trials. Compare against independent calculations or a separate reference model.

300What is the best final check before demonstrating an experiment?Expert

Compile the exact saved source, run a known case, verify the full trace and averages, then explain the assumptions. Do not rely on an old executable that may no longer match the source.
