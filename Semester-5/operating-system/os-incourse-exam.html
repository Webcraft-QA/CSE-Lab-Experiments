Read these assumptions first

Scope: FCFS, nonpreemptive SJF, Round Robin, MFT and MVT only. Scheduling assumes all arrival times are zero, one CPU burst per process and no I/O or context-switch cost. Memory values use one consistent unit (for example KB) and represent memory available to processes after any OS reservation.

TAT = CT - AT; WT = TAT - BT; RT = first start - AT. Here AT = 0, so TAT = CT. Do not use first start as RR waiting time. MFT internal waste excludes empty partitions and tail memory. MVT remaining free memory is not automatically external fragmentation. These are teaching simulations, not actual OS resource managers.

Compile each source separately: gcc -std=c11 -Wall -Wextra fcfs.c -o fcfs. Run ./fcfs < fcfs.in on Linux/WSL. Use the matching filename for the other programs.

PRACTICAL 01

FCFS CPU Scheduling

1. Project name

Implementation of FCFS CPU Scheduling using C

2. Description

Simulate First Come First Served scheduling and calculate waiting and turnaround times. All processes arrive at time zero, so input order is the service order. Each process runs to completion.

3. Algorithm

  1. Start; read n and n positive burst times.
  2. Set time = 0 and totals = 0.
  3. For each process in input order, set WT = time.
  4. Add BT to time; set CT = time and TAT = CT.
  5. Add WT and TAT to their totals.
  6. Print the process table and averages; stop.

4. Source code

/* Standalone C11 teaching simulator. Input formats: README.md. */
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

/* Read bounded integer tokens; reject malformed or out-of-range input. */
static int read_int(const char *label, int low, int high) {
    char token[64], *end;
    long value;
    fprintf(stderr, "%s [%d..%d]: ", label, low, high);
    if (scanf("%63s", token) != 1) {
        fprintf(stderr, "Missing input.\n"); exit(EXIT_FAILURE);
    }
    errno = 0;
    value = strtol(token, &end, 10);
    if (errno || *end || value < low || value > high) {
        fprintf(stderr, "Invalid input: %s\n", token);
        exit(EXIT_FAILURE);
    }
    return (int)value;
}

/* All arrivals are zero; no I/O or context-switch cost. */
int main(void) {
    int n = read_int("Process count", 1, 50);
    int bt[50], order[50], ct[50], wt[50], first[50];
    int time = 0;
    double sum_wt = 0, sum_tat = 0;
    for (int i = 0; i < n; ++i) {
        bt[i] = read_int("Burst", 1, 1000);
        order[i] = i;
    }
    for (int k = 0; k < n; ++k) {
        int i = order[k];
        first[i] = wt[i] = time;
        printf("RUN P%d %d %d\n", i+1, time, time+bt[i]);
        time += bt[i]; ct[i] = time;
    }
    puts("PID BT CT TAT WT RT");
    for (int i = 0; i < n; ++i) {
        printf("P%d %d %d %d %d %d\n", i+1, bt[i], ct[i],
               ct[i], wt[i], first[i]);
        sum_wt += wt[i]; sum_tat += ct[i];
    }
    printf("AVG_WT %.6f AVG_TAT %.6f\n", sum_wt/n, sum_tat/n);
    return 0;
}

Viva preparation

Is FCFS preemptive?

No. It does not interrupt a burst to serve another ready process.

Which queue rule is used?

FIFO: First In, First Out.

What is the convoy effect?

Short processes wait behind a long process.

Why is the first WT zero?

The CPU is available and all arrivals are zero.

Does FCFS cause starvation?

Not for a queued process when jobs ahead finish in finite time.

What if arrivals differ?

Use start = max(previous CT, AT), CT = start + BT and WT = start - AT; order by arrival.

What is its complexity here?

O(n) time and O(n) array storage.

Why is input order used?

All arrivals tie at zero; input order is the chosen tie rule.

PRACTICAL 02

Nonpreemptive SJF CPU Scheduling

1. Project name

Implementation of Nonpreemptive SJF CPU Scheduling using C

2. Description

Simulate Shortest Job First scheduling. All processes arrive at time zero. Select shorter bursts first; equal bursts retain input order. Each selected process runs to completion.

3. Algorithm

  1. Start; read n and burst times; store each original process ID.
  2. Create an order array containing the process indices.
  3. Stable-sort the order array by increasing burst time.
  4. Set time = 0. Visit processes in sorted order.
  5. Set WT = time, add BT to time and set CT = TAT = time.
  6. Print the table with original IDs and the averages; stop.

4. Source code

/* Standalone C11 teaching simulator. Input formats: README.md. */
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

/* Read bounded integer tokens; reject malformed or out-of-range input. */
static int read_int(const char *label, int low, int high) {
    char token[64], *end;
    long value;
    fprintf(stderr, "%s [%d..%d]: ", label, low, high);
    if (scanf("%63s", token) != 1) {
        fprintf(stderr, "Missing input.\n"); exit(EXIT_FAILURE);
    }
    errno = 0;
    value = strtol(token, &end, 10);
    if (errno || *end || value < low || value > high) {
        fprintf(stderr, "Invalid input: %s\n", token);
        exit(EXIT_FAILURE);
    }
    return (int)value;
}

/* All arrivals are zero; no I/O or context-switch cost. */
int main(void) {
    int n = read_int("Process count", 1, 50);
    int bt[50], order[50], ct[50], wt[50], first[50];
    int time = 0;
    double sum_wt = 0, sum_tat = 0;
    for (int i = 0; i < n; ++i) {
        bt[i] = read_int("Burst", 1, 1000);
        order[i] = i;
    }
    /* Stable ascending-key insertion sort; IDs stay attached to data. */
    for (int i = 1; i < n; ++i) {
        int x = order[i], j = i;
        while (j > 0 && bt[order[j-1]] > bt[x]) {
            order[j] = order[j-1]; --j;
        }
        order[j] = x;
    }
    for (int k = 0; k < n; ++k) {
        int i = order[k];
        first[i] = wt[i] = time;
        printf("RUN P%d %d %d\n", i+1, time, time+bt[i]);
        time += bt[i]; ct[i] = time;
    }
    puts("PID BT CT TAT WT RT");
    for (int i = 0; i < n; ++i) {
        printf("P%d %d %d %d %d %d\n", i+1, bt[i], ct[i],
               ct[i], wt[i], first[i]);
        sum_wt += wt[i]; sum_tat += ct[i];
    }
    printf("AVG_WT %.6f AVG_TAT %.6f\n", sum_wt/n, sum_tat/n);
    return 0;
}

Viva preparation

Why choose the shortest burst?

With all jobs ready and bursts known, this order minimizes average waiting time.

What is the preemptive counterpart?

Shortest Remaining Time First, or SRTF.

Can SJF cause starvation?

Yes, in an ongoing workload if short jobs continually arrive ahead of a long job. The finite batch here finishes.

Why sort indices instead of changing IDs?

The order array selects execution order while burst times remain attached to original process IDs.

What if bursts tie?

Stable insertion sort preserves input order by shifting only strictly larger bursts.

Are bursts known in real systems?

Usually they must be estimated.

Does one global sort handle differing arrivals?

No. At each decision, choose only among processes already ready.

What is the sort complexity?

Worst-case O(n squared) time; scheduling after sorting is O(n).

PRACTICAL 03

Round Robin CPU Scheduling

1. Project name

Implementation of Round Robin CPU Scheduling using C

2. Description

Simulate preemptive Round Robin scheduling. All processes arrive at time zero. Each unfinished process receives up to one time quantum per turn, in cyclic input order.

3. Algorithm

  1. Start; read n, positive burst times and a positive quantum.
  2. Copy bursts to remaining[]; set time = done = 0.
  3. Scan processes cyclically, skipping completed processes.
  4. Set run = minimum(remaining time, quantum).
  5. Increase time by run and decrease remaining time by run.
  6. When remaining becomes zero, record CT and increase done.
  7. Repeat until done = n; calculate TAT = CT and WT = CT - BT.
  8. Display results and averages; stop.

4. Source code

/* Standalone C11 teaching simulator. Input formats: README.md. */
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

/* Read bounded integer tokens; reject malformed or out-of-range input. */
static int read_int(const char *label, int low, int high) {
    char token[64], *end;
    long value;
    fprintf(stderr, "%s [%d..%d]: ", label, low, high);
    if (scanf("%63s", token) != 1) {
        fprintf(stderr, "Missing input.\n"); exit(EXIT_FAILURE);
    }
    errno = 0;
    value = strtol(token, &end, 10);
    if (errno || *end || value < low || value > high) {
        fprintf(stderr, "Invalid input: %s\n", token);
        exit(EXIT_FAILURE);
    }
    return (int)value;
}

/* All arrivals zero; initial ready order P1..Pn; zero switching cost. */
int main(void) {
    int n = read_int("Process count", 1, 50);
    int bt[50], remaining[50], ct[50], first[50];
    int time = 0, done = 0;
    double sw = 0, st = 0;
    for (int i = 0; i < n; ++i) {
        bt[i] = remaining[i] = read_int("Burst", 1, 1000);
        first[i] = -1;
    }
    int quantum = read_int("Quantum", 1, 1000);
    while (done < n) {
        for (int i = 0; i < n; ++i) {
            if (!remaining[i]) continue;
            if (first[i] == -1) first[i] = time;
            int run = remaining[i] < quantum ? remaining[i] : quantum;
            printf("RUN P%d %d %d\n", i+1, time, time+run);
            time += run; remaining[i] -= run;
            if (!remaining[i]) { ct[i] = time; ++done; }
        }
    }
    puts("PID BT CT TAT WT RT");
    for (int i = 0; i < n; ++i) {
        int wt = ct[i] - bt[i];
        printf("P%d %d %d %d %d %d\n", i+1, bt[i], ct[i], ct[i], wt, first[i]);
        sw += wt; st += ct[i];
    }
    printf("AVG_WT %.6f AVG_TAT %.6f\n", sw/n, st/n);
    return 0;
}

Viva preparation

What is a quantum?

The maximum CPU time granted in one turn.

What does preemption mean?

The OS interrupts a running process, saves its state and lets another run. The interrupted process resumes later.

Why keep original burst times?

Remaining times decrease; original bursts are required for WT = CT - BT.

What if the quantum is very large?

If it is at least every burst, this model behaves like FCFS.

What if the quantum is very small?

Response can be quicker, but real context-switch overhead increases.

Why reject zero quantum?

Execution would make no progress and the loop would not terminate.

Is response time equal to waiting time?

Not generally. Response is time before first execution; WT includes waiting between turns.

Can a turn be shorter than the quantum?

Yes, when the remaining burst is smaller.

Why use a repeated scan?

All processes arrive at zero and unfinished jobs remain in fixed cyclic order.

What does done count?

Processes whose remaining burst has reached zero.

PRACTICAL 04

MFT Memory Management

1. Project name

Implementation of MFT Memory Management using C

2. Description

Simulate Multiprogramming with a Fixed Number of Tasks using equal fixed partitions. Each admitted process occupies one partition. Report internal fragmentation, unused partitions and the unpartitioned tail separately.

3. Algorithm

  1. Start; read total available memory, partition size and process count.
  2. Compute count = total / block and tail = total % block.
  3. Set used partitions and internal waste to zero.
  4. Read each process size. If size > block, report TOO_LARGE.
  5. Otherwise, if used = count, report NO_PARTITION.
  6. Otherwise allocate one partition, increase used and add block - size to waste.
  7. Print internal waste, count - used unused partitions and tail; stop.

4. Source code

/* Standalone C11 teaching simulator. Input formats: README.md. */
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

/* Read bounded integer tokens; reject malformed or out-of-range input. */
static int read_int(const char *label, int low, int high) {
    char token[64], *end;
    long value;
    fprintf(stderr, "%s [%d..%d]: ", label, low, high);
    if (scanf("%63s", token) != 1) {
        fprintf(stderr, "Missing input.\n"); exit(EXIT_FAILURE);
    }
    errno = 0;
    value = strtol(token, &end, 10);
    if (errno || *end || value < low || value > high) {
        fprintf(stderr, "Invalid input: %s\n", token);
        exit(EXIT_FAILURE);
    }
    return (int)value;
}

/* Equal fixed partitions; no freeing; unused tail is reported separately. */
int main(void) {
    int total = read_int("Total memory", 1, 1000000);
    int block = read_int("Partition size", 1, total);
    int n = read_int("Process count", 1, 100);
    int count = total / block, tail = total % block, used = 0, waste = 0;
    printf("PARTITIONS %d TAIL %d\n", count, tail);
    puts("PID REQUEST RESULT INTERNAL_WASTE");
    for (int i = 0; i < n; ++i) {
        int size = read_int("Request", 1, 1000000);
        if (size > block) printf("P%d %d TOO_LARGE -\n", i+1, size);
        else if (used == count) printf("P%d %d NO_PARTITION -\n", i+1, size);
        else {
            ++used; waste += block-size;
            printf("P%d %d ALLOCATED %d\n", i+1, size, block-size);
        }
    }
    printf("INTERNAL_WASTE %d UNUSED_PARTITIONS %d TAIL %d\n", waste, count-used, tail);
    return 0;
}

Viva preparation

What is internal fragmentation?

Unused space inside an allocated partition: block size minus process size.

Must fixed partitions be equal?

No. MFT may use unequal fixed partitions; this program uses equal ones.

Why can allocation fail with free memory?

A process must fit one partition; it cannot combine several partitions in this model.

What limits resident processes?

The number of partitions, with one process per partition.

Is an unused partition internal waste?

No. It is unallocated memory, not slack inside an allocation.

What does % calculate?

The remainder after forming whole fixed partitions.

Is tail memory internal fragmentation?

No. It is outside the formed partitions and is reported separately.

Does the program release partitions?

No. It models admission only; a full simulator must track termination and reuse.

PRACTICAL 05

MVT Memory Management

1. Project name

Implementation of MVT Memory Management using C

2. Description

Simulate Multiprogramming with a Variable Number of Tasks using a simple single free-memory pool. Allocate exactly the requested amount when it fits. This accounting model does not simulate holes, deallocation or compaction.

3. Algorithm

  1. Start; read total available memory and process count.
  2. Set remaining = total.
  3. For each request, compare size with remaining.
  4. If size <= remaining, allocate and subtract size from remaining.
  5. Otherwise report NOT_ALLOCATED; continue to later requests.
  6. Print allocated memory = total - remaining and remaining free memory; stop.

4. Source code

/* Standalone C11 teaching simulator. Input formats: README.md. */
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

/* Read bounded integer tokens; reject malformed or out-of-range input. */
static int read_int(const char *label, int low, int high) {
    char token[64], *end;
    long value;
    fprintf(stderr, "%s [%d..%d]: ", label, low, high);
    if (scanf("%63s", token) != 1) {
        fprintf(stderr, "Missing input.\n"); exit(EXIT_FAILURE);
    }
    errno = 0;
    value = strtol(token, &end, 10);
    if (errno || *end || value < low || value > high) {
        fprintf(stderr, "Invalid input: %s\n", token);
        exit(EXIT_FAILURE);
    }
    return (int)value;
}

/* Simplified variable-size allocation from ONE free pool, no deallocation.
   This is a single-pool model, not a fragmented hole list.
   A failed request does not stop later requests. */
int main(void) {
    int total = read_int("Total memory", 1, 1000000), remaining = total;
    int n = read_int("Process count", 1, 100);
    puts("PID REQUEST RESULT FREE_REMAINING");
    for (int i = 0; i < n; ++i) {
        int size = read_int("Request", 1, 1000000);
        if (size <= remaining) {
            remaining -= size;
            printf("P%d %d ALLOCATED %d\n", i+1, size, remaining);
        } else printf("P%d %d NOT_ALLOCATED %d\n", i+1, size, remaining);
    }
    printf("ALLOCATED %d FREE %d\n", total-remaining, remaining);
    return 0;
}

Viva preparation

How does MVT differ from MFT?

MVT sizes allocations to requests; MFT uses predetermined partitions.

Does ideal exact-size MVT have internal waste?

No partition-size waste; real systems can have alignment and metadata overhead.

What is external fragmentation?

Free space is split into holes so no single hole satisfies a contiguous request even if the total free space is enough.

Is all remaining memory external fragmentation?

No. A single free region is not evidence of fragmentation.

Does this program demonstrate scattered holes?

No. A single remaining counter cannot describe hole locations or sizes.

What is compaction?

Relocating allocated regions together to combine separated free holes.

Why continue after a failed request?

A later smaller process may fit the remaining space.

What does a full MVT simulator need?

Allocated-region and free-hole lists, a placement policy, deallocation and adjacent-hole merging.

Common viva

What is an operating system?

System software that manages hardware resources and provides services to applications.

What is a process?

A program in execution, including its state and resources.

What is the ready queue?

Processes ready to execute but waiting for CPU time.

What is CPU scheduling?

Selecting a ready process to run on the CPU.

What is burst time?

CPU execution time needed by a process for a burst.

What is turnaround time?

Time from arrival until completion: TAT = CT - AT.

What is waiting time?

Total ready-queue waiting. In the single-burst model, WT = TAT - BT.

What is response time?

First CPU start time minus arrival time.

Why use double totals?

Dividing a double total by n retains a fractional average.

Do these programs change the real OS?

No. They simulate decisions and memory accounting.

What is multiprogramming?

Keeping multiple programs in memory so another can run when one waits.

What is a context switch?

Saving one execution context and restoring another; it takes time in real systems.

What does read_int do?

It reads one integer, validates its range and exits on invalid or missing input.

Why are array indices zero-based?

C arrays start at zero; printing index + 1 gives familiar process labels.
